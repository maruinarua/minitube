# Çözülmüş sürümler — requirements.txt'nin tam karşılığı, alt bağımlılıklar
# dahil. CI bunu kısıt dosyası olarak kullanıyor:
#
#     pip install -r requirements.txt -c requirements-lock.txt
#
# Böylece kurulacak paketler requirements.txt'den, sürümleri ise buradan
# gelir. requirements.txt ile bu dosya birbirinden ayrı düşerse pip çözümü
# yapamaz ve CI kırılır; sessizce eski sürümle test edilmiş olmayız.
#
# Yenilemek için (dört Python sürümünde de aynı çözümü verdiği doğrulandı):
#
#     python -m venv /tmp/lock && /tmp/lock/bin/pip install -r requirements.txt
#     /tmp/lock/bin/pip freeze > requirements-lock.txt
#
# Not: sürümler sabit ama karma (hash) doğrulaması yok. Tedarik zinciri
# garantisi için --require-hashes ayrı bir adım.
